## 7. Calculated Fields & Business Metrics

### A. Profit Margin %

Profit margin measures the percentage of revenue retained as profit.

Formula:

```excel
=IFERROR(Profit/Sales,0)
```

For a PivotTable Calculated Field:

```excel
=Profit/Sales
```

Format the result as Percentage.

### B. Growth %

Growth percentage measures the change in revenue between two periods.

Formula:

```excel
=IFERROR((Current_Sales-Previous_Sales)/Previous_Sales,0)
```

Format the result as Percentage.

**Note:** Growth requires comparable time periods, such as monthly or quarterly revenue. It is calculated using period-wise results rather than a simple standalone row-level calculation.

### C. Total Revenue

```excel
=SUM(Sales_Data[Sales])
```

### D. Total Profit

```excel
=SUM(Sales_Data[Profit])
```

### E. Total Quantity

```excel
=SUM(Sales_Data[Quantity])
```

## 8. Power Query – Data Transformation

**Objective:** Import, clean, combine, and load data from multiple CSV files.

### Step 1: Import CSV Files

1. Open Excel.
2. Select Data → Get Data.
3. Select From File → From Text/CSV.
4. Browse and select the CSV file.
5. Click Transform Data.

### Step 2: Clean Data Using Power Query

Perform the following operations:

- Remove unnecessary columns.
- Remove blank rows.
- Remove duplicate records where appropriate.
- Replace or handle null values.
- Rename columns.
- Change column data types.
- Format numerical fields correctly.

### Step 3: Combine Multiple CSV Files

1. Place CSV files inside one folder.
2. Select Data → Get Data → From File → From Folder.
3. Select the folder.
4. Click Combine & Transform.
5. Verify the column structure.
6. Apply transformations.
7. Click Close & Load.

### Step 4: Refresh Data

Use:

Data → Refresh All

This updates the queries and connected reports when source files change.

## 11. Conditional Formatting – KPI Thresholds

**Objective:** Highlight important business performance indicators using colors.

### A. Profit KPI

| Condition | Formatting |
|---|---|
| Profit > 0 | Green |
| Profit < 0 | Red |
| Profit = 0 | Yellow |

### B. Profit Margin KPI

| Condition | Formatting |
|---|---|
| Margin >= 20% | Green |
| Margin between 10% and 20% | Yellow |
| Margin < 10% | Red |

### C. Sales KPI

Use Conditional Formatting → Data Bars to compare sales values visually.

### D. Discount KPI

| Condition | Formatting |
|---|---|
| Discount > 20% | Red |
| Discount <= 20% | Green |

**Steps:**

1. Select the required KPI cells.
2. Open Home → Conditional Formatting.
3. Select Highlight Cells Rules.
4. Choose the required condition.
5. Select formatting colors.
6. Click OK.

For formula-based formatting, use:

```excel
=B2<0
```

This highlights negative profit values in red when applied to the appropriate Profit range.

## 14. Viva Questions

**Q1. What is a PivotTable?**

A PivotTable is an Excel feature used to summarize and analyze large datasets quickly.

**Q2. What is Power Query?**

Power Query is a data transformation tool used to import, clean, combine, and prepare data.

**Q3. What is the difference between PivotTable and Power Query?**

PivotTable summarizes data, while Power Query cleans and transforms data.

**Q4. What is Power Query M language?**

M is the formula language used by Power Query to perform data extraction and transformation.

**Q5. What is a PivotChart?**

A PivotChart is a chart connected to a PivotTable that updates dynamically when the PivotTable is filtered.

**Q6. What is a Slicer?**

A Slicer is an interactive visual filter used to filter PivotTables and PivotCharts.

**Q7. What is Profit Margin?**

Profit Margin is the percentage of revenue retained as profit.

**Q8. What is Growth Percentage?**

Growth Percentage measures the percentage increase or decrease between two periods.

**Q9. What is Conditional Formatting?**

Conditional Formatting automatically changes cell appearance based on specified conditions.

**Q10. What is the difference between Excel and Python for data analysis?**

Excel is useful for interactive reporting and quick analysis, while Python is suitable for automation, advanced analysis, and large-scale data processing.
